# Friendship-Indicator-SMAPI
This is my very first stardew valley mod. It relies on the SMAPI API. The idea of the mod is to indicate to the player when their friendship with an NPC changes at all. Either in the form of a number above the NPCS head if they are on the current map or a message in the chat if they are not.

### Features
- Whenever friendship is gained or lost it is indicated to the player in one of two ways:
   - NPC is on current map -> +/- and green/red text above their heads
   - NPC is not on current map -> a chat message in the in game chat log
- Whenever a player meets a new npc is message is read out in the in-game chat log, even if the npc is on the current map.

Messages and the alerts are fully customizable.
